# Learn English — אפליקציית לימוד אנגלית

## הפעלה במחשב

**דרישה:** צריך [Node.js](https://nodejs.org) מותקן (גרסה 18 ומעלה). בדקו עם:
```
node -v
```

### שלבים

1. פתחו טרמינל בתוך תיקיית הפרויקט (המקום שבו נמצא הקובץ הזה).
2. התקינו את התלויות:
   ```
   npm install
   ```
3. הריצו את שרת הפיתוח:
   ```
   npm run dev
   ```
4. פתחו בדפדפן את הכתובת שתופיע (בדרך כלל `http://localhost:5173`).

זהו — האפליקציה תרוץ במחשב שלכם. ההתקדמות (סטרייק, מילים שנלמדו וכו') נשמרת בדפדפן המקומי (localStorage), כך שהיא תישאר גם אם תסגרו ותפתחו מחדש — אבל רק באותו דפדפן ומחשב.

### כדי לגשת גם מהנייד באותה רשת

הריצו:
```
npm run dev -- --host
```
ואז פתחו בנייד את הכתובת שתופיע (משהו כמו `http://192.168.x.x:5173`), בתנאי שהנייד והמחשב מחוברים לאותו Wi-Fi.

### בנייה לגרסת ייצור (קובץ סטטי שאפשר להעלות לאחסון אתרים)
```
npm run build
```
התוצאה תיכנס לתיקיית `dist/` — אפשר להעלות אותה לכל שירות אחסון אתרים סטטי.

## פרסום ב-GitHub Pages (בלי Netlify)

הפרויקט כבר כולל קובץ Workflow מוכן ב-`.github/workflows/deploy.yml` שבונה ומפרסם את האתר אוטומטית בכל פעם שמעדכנים את הקוד ב-GitHub.

1. העלו את כל התוכן (כולל תיקיית `.github`) לרפוזיטורי ב-GitHub.
2. בעמוד הרפוזיטורי: **Settings → Pages**.
3. תחת "Build and deployment", ליד "Source" בחרו **GitHub Actions** (לא "Deploy from a branch").
4. עברו ללשונית **Actions** ברפוזיטורי — אמור לרוץ workflow בשם "Deploy to GitHub Pages". חכו שיסתיים (עיגול ירוק).
5. חזרו ל-Settings → Pages — יופיע קישור חי בסגנון `https://<username>.github.io/<repo-name>/`.

מכאן והלאה, כל שינוי שתעלו לענף `main` (גם עריכת קובץ ישירות באתר GitHub) יפעיל בנייה ופרסום מחדש אוטומטית תוך דקה-שתיים — בלי מגבלה על מספר העדכונים, ובלי צורך ב-Netlify.
